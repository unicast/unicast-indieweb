## 🛠 MAINTENANCE PROTOCOLS
This sector is equipped with an automated asset pipeline. To maintain the vault's visual integrity, follow these standard operating procedures:

### 1. Asset Synchronization
Keep your high-resolution original blueprints in the `assets_orig/` sector. To process them for the engine:
```bash
make assets
```

### 2. Sector Configuration
The entire bunker layout—including rooms, lighting, and interactable objects—is governed by the **`config.json`** mainframe. Modify with caution.

### 3. Engine Core
Built with Vanilla Javascript and standard HTML5 Canvas. No external dependencies required for runtime. Optimized for both desktop and mobile terminals.
